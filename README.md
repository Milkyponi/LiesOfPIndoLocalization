Mod lokalisasi Bahasa Indonesia untuk game **Lies of P** (PC Steam) karya **Milkyponi**.

Dibuat khusus bagi pemain yang ingin menikmati kekayaan kisah fabel kelam era Belle Époque di kota Krat, intrik Kaum Alkemis, misteri boneka Pinocchio (P), hingga ekspansi **DLC Overture** dalam Bahasa Indonesia yang natural, sastrawi, dan sarat emosi—tanpa merusak istilah-istilah gameplay penting.

---

## 🌟 Fitur Utama (Context-Aware Translation)

1. **Terjemahan Kontekstual Berbasis Adegan (Context-Aware Narrative)**:
   - Seluruh naskah narasi (5.110 baris terverifikasi) diterjemahkan secara *scene-level* per adegan percakapan utuh, bukan terjemahan mesin kaku perkata.
   - Persona dan karakterisasi unik tiap tokoh dijaga ketat:
     - **Geppetto**: Hangat kebapakan namun menyimpan wibawa dingin seorang pencipta (*"Anakku yang baik"*).
     - **Sophia**: Anggun, melankolis, penuh kasih sayang dan empati mendalam.
     - **Gemini (Jangkrik Lentera)**: Akrab, ceria, sedikit cemas tapi setia mendampingi P sebagai pemandu.
     - **Lorenzini Venigni**: Flamboyan, teatrikal, narsis elegan khas bangsawan industrialis jenius.
     - **Arlecchino (The King of Riddles)**: Menyeramkan, puitis berima, sarkastik gila lewat bilik telepon umum.
     - **Simon Manus**: Megalomania, berwibawa mistis, dan dingin menghadapi kejatuhan peradaban Krat.

2. **Dokumen Koleksi Lore Tuntas (Notes, Letters & Cryptic Vessels)**:
   - Seluruh 764 naskah dokumen koleksi (surat korban, catatan penumpang di stasiun, buku harian penambang, selebaran buronan Stalker, koran berita Krat, hingga teka-teki Cryptic Vessels) kini 100% berbahasa Indonesia.

3. **Dukungan Penuh DLC Overture**:
   - Seluruh 1.168 baris narasi ekspansi **DLC Overture** tuntas diterjemahkan:
     - Karakter baru: **Alex**, **Lea** (sang *Legendary Stalker*), **Lumacchio** (Snail), **Sang Nelayan** (Fisherman), dan **Rosaura**.
     - Eksplorasi wilayah Ruin, Kebun Binatang Krat (Krat Zoo), salju musim dingin, rekaman masa lalu Geppetto & Carlo, hingga cutscene dan ending khusus Overture.

4. **Teks Inspeksi Lingkungan Aktif (Environmental Lore)**:
   - Coretan dinding Romeo (*"- Aku, Romeo, akan menjadi Stalker terhebat di seluruh Krat!"*), catatan meja kerja Eugénie di Hotel Krat, plang karantina Penyakit Membatu, prasasti patung malaikat, dan catatan kupu-kupu rahasia kini menyapa dalam Bahasa Indonesia saat Anda berinteraksi dengan objek dunia.

5. **UI, Senjata, Item & Skill Tetap 100% Original English**:
   - Seluruh antarmuka menu, bilah & gagang senjata (*Weapon Blade & Handle*), *Fable Arts*, *Quartz*, *Ergo*, *P-Organ*, *Legion Arm*, dan item buff tetap 100% Bahasa Inggris original agar panduan build di internet tetap mudah diikuti.

6. **Pengecualian Tutorial (Hybrid Mapping)**:
   - Judul tutorial dan pemetaan tombol kontrol tetap asli (misal: `<LeftShoulder>: Guard`, `(A) Next`). Hanya paragraf penjelasan mekaniknya yang diterjemahkan ke Bahasa Indonesia yang luwes.

7. **Zero Modloader Dependency & 0% Background Overhead**:
   - Berupa patch mod native Unreal Engine 4 (`~mods/LiesofP_Indo_P.pak`).
   - Tidak membutuhkan modloader pihak ketiga atau script latar belakang. Rig dan FPS Anda tetap 100% aman dan mulus untuk gaming dan streaming.
   - 100% kompatibel dengan save game dan pencapaian Steam Achievements.

## 📥 Panduan Instalasi (Cara Pasang)

### Langkah Cepat (Steam PC):
1. Unduh asset **`LiesofP_Indo_v1.2.zip`** dari halaman [**Releases**](https://github.com/Milkyponi/LiesOfPIndoLocalization/releases).
2. Buka folder instalasi game **Lies of P**:
   - Buka **Steam Library** -> Klik kanan pada **Lies of P** -> Pilih **Manage** -> **Browse local files**.
   - Lokasi default Windows biasanya:  
     `C:\Program Files (x86)\Steam\steamapps\common\Lies of P\LiesofP\Content\Paks\`  
     *(atau di drive library tempat Anda menginstal game, misalnya `D:\SteamLibrary\steamapps\common\Lies of P\LiesofP\Content\Paks\`)*.
3. Di dalam folder **`Paks`**, buat folder baru bernama **`~mods`** (jika belum ada):  
   `.../Lies of P/LiesofP/Content/Paks/~mods/`
4. Ekstrak atau salin file **`LiesofP_Indo_P.pak`** langsung ke dalam folder **`~mods`** tersebut.
5. Buka game **Lies of P** dan mainkan! (Pastikan pengaturan bahasa teks game di menu *Settings -> Text Language* adalah **English**).

---

### Panduan untuk Linux / Steam Deck:
1. Buka folder instalasi game di Desktop Mode:  
   `~/.steam/steam/steamapps/common/Lies of P/LiesofP/Content/Paks/~mods/`
2. Letakkan file **`LiesofP_Indo_P.pak`** ke dalam folder **`~mods`**.
3. Kembali ke Gaming Mode dan jalankan game seperti biasa!

---

## 🔄 Cara Uninstall (Kembali ke Versi Asli)

Cukup hapus file **`LiesofP_Indo_P.pak`** dari folder **`~mods`**.  
Game Anda seketika kembali 100% ke kondisi original tanpa perlu install ulang atau verifikasi file Steam.
